# SOP-OT: Other disputes (mock)

## SOP-OT-01 Technical failure
If the system log shows a debit without a credit, check for an automatic reversal and route the case to
technical operations.

## SOP-OT-02 Agent-point disputes
Disputes about a transaction at an agent point go to the distributor responsible for that agent first,
and to the MFS provider second (Bangladesh MFS Regulations 2022 §17.5).

## SOP-OT-03 False claims
If the ledger shows repeated earlier payments to the same number, the transfer is unlikely to be a
wrong-send. Reject with an explanation, offer the merchant-dispute route, and require supervisor approval.

## SOP-OT-04 Missing information
If no transaction can be matched, ask the customer for the amount, the number, the approximate time or the
TrxID from their SMS. Never ask for a PIN or OTP.
